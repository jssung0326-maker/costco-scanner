# 코스트코 가격 계산기 V4

## V4 변경사항
- 상품 바코드와 진열대 가격을 각각 따로 인식
- 바코드 + 가격 인식이 끝나면 구입 수량 기본값은 1개
- 수량 옆의 `−` / `＋` 버튼으로 1개씩 감소/증가
- `선택 취소` 버튼으로 아직 장바구니에 넣지 않은 상품을 취소하고 처음부터 다시 스캔
- 장바구니에 들어간 뒤에도 각 상품의 `−` / `＋` 버튼으로 수량 변경
- 장바구니의 `상품 삭제` 버튼으로 해당 상품을 완전히 제거
- 방금 추가 취소 기능 유지

## 사용 흐름
1. 상품 포장지의 바코드 촬영
2. 진열대 가격 촬영
3. 수량 선택 (기본 1개)
4. 장바구니에 추가
5. 필요하면 장바구니에서 수량 조정 또는 상품 삭제

## GitHub 업데이트
기존 저장소의 파일들을 V4 파일들로 교체/덮어쓰기하면 됩니다.
GitHub Pages 설정(main / root)은 그대로 유지합니다.
