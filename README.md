# 코스트코 가격 계산기 V2

개인용 iPhone PWA입니다.

## V2 핵심 방식
진열대 가격표에 바코드가 없어도 됩니다.

한 번의 촬영 화면에 다음 두 가지를 같이 넣습니다.

1. 위쪽 파란 안내영역: 실제 상품 포장지의 바코드
2. 아래쪽 초록 안내영역: 진열대 가격표의 가격 숫자

촬영하면 상품 바코드로 상품을 구분하고, 진열대 가격 숫자를 OCR로 읽어 장바구니에 1개를 추가합니다.
같은 상품을 2개 구입하면 같은 상품/가격을 두 번 촬영하면 수량이 2개가 됩니다.

## 기능
- 아이폰 카메라 실행
- 상품 바코드 + 진열대 가격을 한 화면에서 동시에 촬영
- 바코드는 상품 식별용
- 가격 OCR은 화면 하단 가격 전용 영역만 분석
- 같은 바코드는 같은 상품으로 묶어 수량 증가
- 현재 총액/수량 계산
- 방금 추가 취소
- 수량 +/-
- 직접 입력
- 장바구니 브라우저 저장

## 바코드가 인식되지 않았을 때
가격이 정상 인식되면 결과 화면에서 가격만 추가할 수 있습니다.
이 경우 같은 가격의 다른 상품이 잘못 합쳐지지 않도록 별도 항목으로 저장합니다.

## 아이폰 설치
카메라 기능 때문에 HTTPS 주소에서 실행하는 것을 권장합니다.

1. 폴더 전체를 GitHub Pages / Netlify / Cloudflare Pages 등에 업로드합니다.
2. 만들어진 https:// 주소를 iPhone Safari에서 엽니다.
3. 공유 버튼 -> 홈 화면에 추가
4. 홈 화면의 코스트코 계산기 실행
5. 카메라 접근 허용

## 주의
- 실제 인식률은 매장 조명, 반사, 바코드 크기, 가격표 글자 크기에 영향을 받습니다.
- 웹브라우저의 바코드 API 지원 여부에 따라 바코드 인식이 제한될 수 있습니다. 이 경우 직접 입력 기능을 사용할 수 있습니다.
- 실제 코스트코 현장 사진을 몇 장 확보하면 가격 영역 비율과 OCR 규칙을 더 정확하게 조정할 수 있습니다.
